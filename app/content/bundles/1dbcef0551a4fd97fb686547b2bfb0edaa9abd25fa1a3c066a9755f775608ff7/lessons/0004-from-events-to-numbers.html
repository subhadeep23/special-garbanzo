0 · Spaced recall — no peeking

• What are the three columns of the branch table, and which cell answers total probability?

• Two events can't happen together. Are they independent? (Careful.)

Answers: prior, likelihood, branch weight — the column sum of the weights is the total probability. And no: mutually exclusive events with positive probability are never independent, because knowing one happened tells you the other didn't.

1 · The idea: attach a number to every outcome

Toss a fair coin three times. The sample space has eight outcomes: HHH, HHT, HTH, THH, HTT, THT, TTH, TTT. Listing them is tedious, and usually you don't care which outcome happened — you care about something like how many heads.

So give each outcome a number: its count of heads. HHH gets 3. HTT gets 1. TTT gets 0. That's it — you've made a random variable.

Say it in one line

A random variable is a rule that gives every outcome of an experiment a real number. The randomness lives in the outcome; the variable just reads a number off it.

Two things to notice, because both show up as exam statements:

1It is a function, not a variable in the algebra sense. Written X(ω): outcome ω goes in, a number comes out.
2Probability is not in the definition. You can define "number of heads" before anyone tells you whether the coin is fair. The probabilities come from the sample space, and the variable carries them along.
Deeper layer (optional): the one extra rule a random variable must obey

Safe to skip on a busy week.

F(x) will need a chance for "X is at most x". Some setups can't give every group of outcomes a chance.

Example. Three coins are tossed behind a screen. A friend tells you only whether the first toss was heads. So you see only two boxes:

BoxOutcomes inside
first toss HHHH, HHT, HTH, HTT
first toss TTHH, THT, TTH, TTT

Is the number of heads at most 0? That is TTT alone, a sliver of the T box. Your friend can't settle it. So "number of heads" is not a random variable here.

But "1 if the first toss is H, else 0" is fine. "At most 0" is exactly the T box.

The rule: every question "is X at most x?" must be a group that gets a chance.

The textbook words for this

The groups that get a chance form a σ-field (say "sigma-field"). Here it has four members: nothing, the H box, the T box, everything.

A rule that passes is called a measurable function. "Borel-measurable" in the notes means the same thing.

In ordinary coin, dice and card problems, every group of outcomes gets a chance. So every rule you write down passes.

3 · The distribution function: a running total

Now ask a different question at every point on the number line: what's the chance X is at most this? Walk left to right and keep a running total.

F(x) = P(X ≤ x)

the distribution function (d.f.), also called the cumulative distribution function (c.d.f.)

Before you drag anything: three fair coin tosses, X = number of heads. Are P(X ≤ 1) and P(X < 1) the same number? Commit to a yes or no, and guess both values.

Check your guess

No. "At most 1" means 0 or 1 heads: 1/8 + 3/8 = 4/8. "Less than 1" means 0 heads only: 1/8. They differ by P(X = 1) = 3/8, the jump at 1. Now find both on the staircase below.

Drag the cursor (or press Walk it) and watch both readings. Then read the symbols: F is the running-total function; x is any real number you choose — not only 0, 1, 2, 3; ≤ means "at most", including x itself.

Check one by hand: F(2.75) = P(X ≤ 2.75) = every outcome except HHH = 7/8. Any x works, not just whole numbers.

4 · Four properties — every distribution function has them

Look at the staircase and each property is obvious. The exam asks "which of these is a valid d.f.?", and these four are the checklist.

1Never goes down — a running total of probabilities can't shrink. (non-decreasing)
2Starts at 0 far to the left: F(x) → 0 as x → −∞.
3Ends at 1 far to the right: F(x) → 1 as x → +∞.
4At a jump, F takes the upper value — the filled dot. Approaching from the right, you land on F(x) itself. (right-continuous)

Property 4 comes straight from the ≤ in the definition: at x = 1, "at most 1" already includes X = 1, so the jump has happened.

5 · Reading probabilities off the staircase

Write F(a−) for the height just before the jump at a — the hollow dot. Then:

You wantRead it asWhy
P(X ≤ a)F(a)the definition
P(X < a)F(a−)stop just before a — don't take the jump
P(X = a)F(a) − F(a−)the height of the jump at a
P(X > a)1 − F(a)complement of "at most a"
P(a < X ≤ b)F(b) − F(a)up to b, minus up to a

A savings balance. Think of F as a bank balance that starts at 0 and only ever receives deposits of probability, ending at exactly 1. F(x) is the balance at the end of day x, so a deposit made on day x is already counted: that's the ≤, and the filled dot. F(x−) is the balance at the start of day x, before that day's deposit: that's the <, and the hollow dot. The size of the deposit on day x is P(X = x).

Where it breaks: a real balance changes only on separate days. A smooth F (Lesson 5) rises continuously with no single deposit day: every single point brings a deposit of 0, yet the balance still climbs from 0 to 1.

"P(X < a) and P(X ≤ a) are the same thing; the bar under the sign is just fussiness." Wrong for a staircase. For a staircase, < and ≤ give different answers at a jump. P(X ≤ 1) = 4/8 but P(X < 1) = 1/8. Where F is smooth (no jump), they agree, and P(X = a) = 0. Before computing anything, ask: is there a jump at this point?

6 · Exam-shaped problem, worked

A random variable has distribution function

F(x) = 0 for x < 0;   x/4 for 0 ≤ x < 1;   1/2 for 1 ≤ x < 2;   x/12 + 1/2 for 2 ≤ x < 3;   1 for x ≥ 3.

Find (a) P(X < 2), (b) P(X = 2), (c) P(2 < X ≤ 7).

This one is a mix: some pieces slope smoothly, some jump. Find the jumps first by checking each boundary.

(a) Just before 2, F sits on the flat piece: F(2−) = 1/2. So P(X < 2) = 1/2.

(b) At 2, F switches to 2/12 + 1/2 = 2/3. Jump = 2/3 − 1/2 = 1/6. So P(X = 2) = 1/6.

(c) F(7) − F(2) = 1 − 2/3 = 1/3.

In one or two sentences of your own: the pieces of this F on both sides of 2 are sloped or flat, so why does the single point 2 still carry probability 1/6?

Compare with a model answer

Because F jumps at 2: its value just before 2 is 1/2 and its value at 2 is 2/3. Probability at a single point is the size of the jump there, F(2) − F(2−) = 1/6, whatever the pieces around it look like.

Your turn, half done. Same F. Find (d) P(X = 1) and (e) P(X > 2.5).

(d) Just before 1, F is on the piece x/4, so F(1−) = ____. At 1, F(1) = ____. The jump is ____ .

(e) P(X > 2.5) = 1 − F(2.5), and 2.5 is on the piece x/12 + 1/2, so F(2.5) = ____, and the answer is ____ .

Check your steps

(d) F(1−) = 1/4 and F(1) = 1/2, so P(X = 1) = 1/2 − 1/4 = 1/4. (e) F(2.5) = 2.5/12 + 1/2 = 5/24 + 12/24 = 17/24, so P(X > 2.5) = 1 − 17/24 = 7/24.

WATCH OUT  The corpus prints (c) as 1 − (3/12 + 1/2), which would give 1/4. The printed answer, 1/3, is right — the working plugged in 3 where it should use 2. That's the third confirmed OCR slip in this corpus. Keep re-deriving.

You drew F from a model. You can also draw it straight from data.

Toss three coins 8 times for real, and count heads each time. Say you get 1, 2, 2, 0, 1, 2, 3, 2. At each x, ask: what fraction of my 8 results is at most x?

xResults at most xFrom dataTrue F(x)
01 of 81/81/8
13 of 83/84/8
27 of 87/87/8
38 of 811

The data column is a staircase too: it rises 1/8 for each result. It is called the empirical distribution function. Here it misses the truth by at most 1/8, at x = 1. Toss many more times and the gap shrinks toward 0.

Two places you will meet it again

Testing a model (Unit V). Is the coin really fair? Lay the data staircase over the fair-coin staircase and find the biggest vertical gap. A big gap is evidence against fairness. That gap is the Kolmogorov–Smirnov statistic.

Simulation. Read the true staircase sideways. Pick a random height between 0 and 1, then walk right until you hit a step. Heights up to 1/8 land on 0 heads, from 1/8 to 4/8 on 1 head, and so on. So each value comes up with exactly its probability. Computers use this trick to draw from any distribution.

The promise that the gap shrinks to 0 as data grows is the Glivenko–Cantelli theorem.

Why this matters for you

EXAM  "Is this a valid d.f.?" and "compute P(a < X ≤ b) from this F" are staple Unit I questions, and the </≤ jump trap is where marks leak. Everything after this lesson — mass functions, densities, expectation, every named distribution — is a way of describing F.

Go deeper — one proof, one ISI problem (optional, ~20 min)

Prove it

From Lesson 1's three rules alone, prove that every distribution function is non-decreasing, and that for a < b:

P(a < X ≤ b) = F(b) − F(a)

Worked proof

For a < b, the event {X ≤ b} splits into two pieces that can't overlap: {X ≤ a} and {a < X ≤ b}. By Rule 3,

F(b) = F(a) + P(a < X ≤ b)

Rearranging gives the formula. And the last term is a probability, so it is at least 0 by Rule 1. Hence F(b) ≥ F(a): F never goes down. ∎

Property 4 (right-continuity) needs one more tool, continuity of probability along shrinking events. Lesson 5's Go-deeper proof uses the same tool from the other side.

An ISI entrance problem

Here is a real ISI question, in plain words first. Find every distribution function F that gives the same height at a number and at that number raised to the power 2023.

Source: ISI M.Stat 2023, descriptive paper (PSB), Q3. Official wording: "Identify, with justification, all cumulative distribution functions F that satisfy F(x) = F(x²⁰²³) for every x ∈ ℝ."

2023 is just a big odd number. Swap it for 3 so you can watch, and play with the rule F(x) = F(x³) first. Watch the chain step by step, then try it yourself in the picture after it.

Now try it yourself: pick a start and press Cube it.

Worked solution, in five small steps

1 · Shrink the scary number. Think with 3 in place of 2023. Every step below works the same for 2023; the hops are just bigger.

2 · Use the rule again and again. Start at 2. The rule says F(2) = F(8). Use it again on 8, and so F(2) = F(8) = F(512). That is one chain of equal heights.

3 · Follow each chain to its end. Every height in a chain is the same number. So it must equal the height where the chain ends up.

StartCube again and againThe chain heads toSo F(start) is
28, 512, …far right1
−2−8, −512, …far left0
1/21/8, 1/512, …0, from the rightF(0)
−1/2−1/8, −1/512, …0, from the leftF(0−)

Far right, every F climbs to 1 (property 3). Far left, it sinks to 0 (property 2).

The last two rows use the dots from Section 5. Creeping to 0 from the right, F's heights settle on the filled dot, F(0) (property 4). From the left, they settle on the hollow dot, F(0−).

Any start above 1 acts like 2, and any start between 0 and 1 acts like 1/2. The negative side mirrors this.

4 · Read off the shape. So F is flat on four stretches: left of −1, between −1 and 0, between 0 and 1, and right of 1. A flat stretch holds no probability. F can only jump at −1, 0 and 1, the numbers that cubing leaves in place. So X takes only the values −1, 0 and 1.

5 · Check the other direction. Take any chances on −1, 0 and 1. Its staircase is flat on each of the four stretches. A number between 0 and 1 stays between 0 and 1 when cubed, and one above 1 stays above 1. Negatives mirror this, and −1, 0, 1 stay put. So x and x³ always get the same height, and F passes.

Answer: exactly the distributions that put all their probability on −1, 0 and 1, in any proportions.

Checked by computer, with x²⁰²³ computed exactly. 1,000 random distributions on −1, 0 and 1 all pass at 19 test points from −3 to 50. Putting probability at −0.5, 0.5, 0.7 or 2 breaks it.
